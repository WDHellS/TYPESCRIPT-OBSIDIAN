### 📦 Title Bar
🔸 **Interactive Custom Text for altering Note Name**

|     |     |     |
| --- | --- | --- |
| **Disables** | 🔹 | *Title Navigation and Note Name Information* |
| **Displays** | 🔹 | *Custom Text* - becoming the **Title Bar** |
| **Clicking** | 👆🏻 | **restores**: *Title Navigation and Note Name Information* |
| **Clicking** | 👆🏻 | elsewhere, **restores**: *Custom Text* |

 `Settings > WDS.DarkBrain®Notes > Interface Options > Note Navigation :` **Title Bar**<br>
🔶 : *Purpose* : *enable focus to personal environment of note taking*;<br>
🔹 disabled for external Valt files

### 📦 Navigation Bar
🔸 **Interactive row of Custom Buttons**

|     |     |     |
| --- | --- | --- |
| **Inserts**  | 🔹 | per note, **Note Navigation Bar**  |
| **Includes** | 🔹 | **Emoji Icon**, disables: per note. **enables**: **Note Navigation Bar** by default  |
| **Clicking** | 👆🏻 | **launches**: Add Navigation Button Dialog |
| **Includes** | 🔹 | **Main Note**, changes: left-click. **enables**: open selected **Main Note**  |
|              | 👆🏻 | right-click, **launches**: Add Navigation Button Dialog |

|     |     |     |
| --- | --- | --- |
| **Inserts**  | 🔹 | **Button** |
| **Includes** | 🔹 | set Custom Button Color |
| **Clicking**  | 👆🏻 | left-click, open selected **Note** |
| **Clicking**  | 👆🏻 | right-click, edit selected **Note** button |

<sub>auto-hides middle long note scroll, reappears at top\bottom scroll</sub><br>
`Settings > WDS.DarkBrain®Notes > Interface Options > Note Navigation :` **Navigation Bar**<br>
🔶 : *Purpose* : *enable custom organization upon note navigation relevance*;<br>
🔹 editable through Properties Metadata<br>
🔹 access through Slash Commands<br>
🔹 access through Command Palette<br>

### 📦 Pattern Detection
🔸 **Enables WDS.DarkBrain®Notes idealized structure.**

`Settings > WDS.DarkBrain®Notes > Interface Options > Theming :` **Pattern Detection**<br>

🔹 renders decorative elements for headings.<br>
🔹 renders DarkBrain-Emphasis
  - <details>
    <summary>descriptions</summary>
     <sub>styles a paragraph, adds emoji, color, centered, and fold boundary to emphasis</sub><br>

     <img src="https://i.imgur.com/RMWuuGU.gif" title="DarkBrain-Emphasis illustration based on the code below" />
   
     <pre>
     %%darkbrain--emphasis[🎃]:orange%%
     **this is a paragraph to be styled** #TagSample 
     also enables in Reading Mode an interactive icon area at the top-left of
     the paragraph allowing for opening a dialog for emphasis customization
   
     this paragraph is not styled</pre>

    🔶 : <i>Purpose</i> : <i>enable easy note structure for style organization concepts</i>;<br>
    🔹 access through Context Menu <sub>appears only for valid paragraphs</sub><br>
    🔹 customizable through Emphasis Dialog
    </details>
