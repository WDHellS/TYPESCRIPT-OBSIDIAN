### 📦 Title Bar
🔸 **Interactive Custom Text for altering Note Name**

|     |     |     |
| --- | --- | --- |
| **Disables** | 🔹 | *Title Navigation and Note Name Information* |
| **Displays** | 🔹 | *Custom Text* - becoming the **Title Bar** |
| **Clicking** | 👆🏻 | **restores**: *Title Navigation and Note Name Information* |
| **Clicking** | 👆🏻 | elsewhere, **restores**: *Custom Text* |

- Settings > WDS.DarkBrain®Notes > Interface Options > Note Navigation : **Title Bar**

%%darkbrain--emphasis[🔶]%%
enable focus to personal environment of note taking;
🔹 disabled for external Valt files

### 📦 Fold Headings
🔸 **Interactive Button for Headings Management**

|     |     |     |
| --- | --- | --- |
| **Clicking** | 👆🏻 | Collapse\\Expand Headings |

|  options  | |
| --- | --- | 
|0| **Left-Click**:   Fold\\Expand **All** Headings |
|1| **Left-Click**:   Fold\\Expand Headings **I**<br>**Right-Click**:  Fold\\Expand Headings **II** |
|2| **Left-Click**:   Fold\\Expand Headings **I**<br>**Right-Click**:  Fold\\Expand Headings **III to VI** |
|3| **Left-Click**:   Fold\\Expand Headings **II**<br>**Right-Click**:  Fold\\Expand Headings **III to VI** |
|4| **Left-Click**:   Fold\\Expand Headings **I**<br>**Middle-Click**: Fold\\Expand Headings **II**<br>**Right-Click**:  Fold\\Expand Headings **III to VI** |
|5| **Left-Click**:   Fold **II then I**, expand **I then II**<br>**Right-Click**:  Fold\\Expand Headings **III to VI** |
|6| **Left-Click**:   Fold\\Expand Headings **I and II**<br>**Right-Click**:  Fold\\Expand Headings **III to VI** |

|     |     |     |
| --- | --- | --- |

| **Includes** | 🔹 | **Emoji Icon**, disables: per note. **enables**: **Note Navigation Bar** by default  |
| **Clicking** | 👆🏻 | **launches**: Add Navigation Button Dialog |
| **Includes** | 🔹 | **Main Note**, changes: left-click. **enables**: open selected **Main Note**  |
|              | 👆🏻 | right-click, **launches**: Add Navigation Button Dialog |

|     |     |     |
| --- | --- | --- |
| **Inserts**  | 🔹 | **Button** |
| **Includes** | 🔹 | set Custom Button Color |
| **Clicking**  | 👆🏻 | left-click, open selected **Note** |

- auto-hides middle long note scroll, reappears at top\bottom scroll
- Settings > WDS.DarkBrain®Notes > Interface Options > Note Navigation : **Navigation Bar**

### 📦 Pattern Detection
🔸 **Enables WDS.DarkBrain®Notes idealized structure.**

- Settings > WDS.DarkBrain®Notes > Interface Options > Theming : **Pattern Detection**

#### 🔹 renders decorative elements for headings.
- folder emoji and animation to collapsed headings
- wds-darkbrain-notes structure, adds separators to sequenced expanded headings level 1 and 2

#### 🔹 renders DarkBrain-Emphasis
example, add `%%darkbrain-emphasis%%` to style a paragraph
```markdown
 %%darkbrain--emphasis[🎃]:orange%%
 **this is a paragraph to be styled** #TagSample 
 also enables in Reading Mode an interactive icon area at the top-left of
 the paragraph allowing for opening a dialog for emphasis customization

 this paragraph is not styled
```
